# Car Tycoon — отчёт балансировочного симулятора

Сгенерировано `node --no-warnings scripts/simulate.ts` на реальных формулах игры, 3000 машин на класс и стратегию.
«Хорошая сделка» — лучшая четверть объявлений по прибыли на день занятия слота: игрок выбирает, а не покупает всё подряд.
Продажа — лучший для прибыли/день вариант ползунка: −10% сразу, 0% и +10% — за 6/12, 8/16, 10/20, 12/24, 15/30, 15/30 дней по классам. 1 игровой месяц = 5 минут игры.
